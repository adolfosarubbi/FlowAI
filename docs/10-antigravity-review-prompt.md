# Antigravity Self-Review Prompt

Before moving to the next phase, review the implementation you just created against README.md and /docs.

Do not add new features.

Inspect:

- acceptance criteria
- architecture consistency
- TypeScript correctness
- NestJS module boundaries
- Prisma configuration
- security/configuration
- secrets
- error handling
- tests
- Docker setup
- CI setup
- unnecessary dependencies/abstractions
- documentation accuracy

Then:

1. list BLOCKERS
2. list IMPORTANT issues
3. list NICE-TO-HAVE items
4. list missing tests
5. fix BLOCKERS and IMPORTANT issues that are within the current phase
6. rerun validation/tests/build
7. provide final status

Do not implement anything from the next backlog phase.
