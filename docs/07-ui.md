# UI Specification

## Login

Email/password and demo-account access.

## Dashboard

KPI cards, pipeline distribution, recent conversations, due tasks.

## Inbox

Three-column desktop layout:

- conversations
- messages/composer
- contact + lead + AI qualification

## Leads

Search/filter by stage, owner, intent, urgency and date.

## Pipeline

Kanban with drag/drop.

## Lead detail

Contact, qualification, value, timeline, tasks and linked conversation.

## Tasks

My tasks, overdue and upcoming.

## Settings

Workspace, members, WhatsApp and AI settings.

## UX principles

- desktop-first responsive admin application
- clear states: loading/empty/error/success
- keyboard-friendly where practical
- no excessive animations
- prioritize speed and information hierarchy
